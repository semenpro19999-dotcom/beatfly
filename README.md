# BeatFly: Drosophila Beat Saber (Neuro-RL) 🪰⚔️🎵

Интерактивный проект, в котором 3D-муха дрозофила (*Drosophila melanogaster*) играет в Beat Saber двумя миниатюрными световыми мечами, обучаясь попадать по ритмическим блокам через подкрепление:
* **За попадание** — мощный выброс **дофамина** (+Reward, синаптическая потенциация в грибовидном теле мозга).
* **За промах** — **«бобо»** (-Penalty, ноцицептивный аверсивный шок, ослабление синапсов и коррекция моторной траектории).

Проект опирается на реальный датасет коннектома дрозофилы из **`neurons.csv`** (166 700 идентифицированных нейронов FlyWire/Janelia).

## 1. Считается ли это издевательством над мухой? 🔬

### В реальной нейробиологии:
* **Модельный организм №1:** Мушка *Drosophila melanogaster* — один из фундаментальных модельных организмов мировой науки (за исследования на ней присуждено **6 Нобелевских премий**).
* **Как ученые обучают реальных мух:** С 1970-х годов (классические опыты Сеймура Бензера, Талли и Куинна) мух обучают ассоциациям именно так:
  * **Награда (Reward):** капля сахара $\rightarrow$ выброс дофамина через нейроны кластера **PAM**.
  * **«Бобо» (Punishment):** легкий электрический импульс или локальный нагрев $\rightarrow$ активация ноцицепторов и дофаминовых нейронов кластера **PPL1**, формирующих реакцию избегания.
* **Биоэтический статус:** Законодательства о защите животных (Animal Welfare) большинства стран регулируют эксперименты только на позвоночных и некоторых высших моллюсках. У дрозофилы нет коры полушарий и субъективного «страдания» в человеческом смысле, но развита рефлекторная **ноцицепция** (быстрый уход от опасности через гигантские волокна `DNp01`).

### В нашей цифровой симуляции:
* **Ни одна реальная муха не страдает!** 
* Это математическая модель обучения с подкреплением (**Reinforcement Learning**):
  $$Q(s, a) \leftarrow Q(s, a) + \alpha \cdot \big(R + \gamma \max Q(s', a') - Q(s, a)\big)$$
  где $R = +10$ при выбросе дофамина и $R = -12$ при «бобо».
* Это цифровой трибьют удивительной нервной системе насекомого!

## 2. Структура проекта для Godot 4 🎮

В репозитории подготовлены полные исходники для **Godot Engine 4.x**:

* `project.godot` — конфигурация проекта Godot 4 (3D Forward+/Compatibility, окно 1280x720).
* `scripts/fly_brain_rl.gd` — биологический мозг мухи на GDScript (грибовидное тело, клетки Кеньона, выброс дофамина PAM и ноцицепция PPL1).
* `scripts/fly_model_3d.gd` — 3D-модель мухи: трепетание крыльев с частотой 200 Гц, сияющие фасеточные глаза, взмахи световыми мечами, рефлекторная дрожь при «бобо».
* `scripts/cube_3d.gd` — 3D-кубики Beat Saber, летящие навстречу мухе и разрубаемые на физические осколки.
* `scripts/beat_saber_track.gd` — дирижер ритм-трека и спавнер блоков.
* `scenes/main_beatfly.tscn` — готовая 3D-сцена со световыми эффектами, камерой и HUD.

## 3. Интерактивная веб-версия (Three.js + Web Audio) 🌐

Для мгновенного тестирования прямо в браузере реализована WebGL/Three.js версия с процедурным синтезатором музыки:

### Запуск локально:
```bash
npm install
npm run dev
```

### Управление:
* **Кнопка «МУХА УЧИТСЯ САМА»** — автономный режим: муха на сверхчеловеческой скорости рубит блоки, демонстрируя реакцию на дофамин и ошибки.
* **Мышь:** Управление лапками мухи в ручном режиме.
* **ЛКМ:** Взмах левым мечом (Cyan, ацетилхолиновые пути).
* **ПКМ / Пробел:** Взмах правым мечом (Red, дофаминовые пути).
* **Переключение камер:** Вид сзади, вид из фасеточных глаз мухи, экшн-камера.
